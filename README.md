# ATK 工作室 · 新人学习进度管理系统

管理 ATK 工作室新人的四阶段学习进度，并记录每一次学习打卡。
**网页版（PC）+ 手机端** 两套界面，共用同一套后端接口与同一份数据，多端实时同步。

## 启动

```bash
npm start          # 或 node server/index.js，默认 3000 端口
PORT=8080 npm start
```

- 网页版（PC）：http://localhost:3000/
- 手机端：http://localhost:3000/m/
- 根路径会按设备 UA 自动判断跳转；加 `?v=web` 可强制打开网页版

零外部依赖（只用 Node 内置模块），数据落在 `data/db.json`。

## 默认账号

| 账号 | 密码 | 角色 | 能看到什么 |
| --- | --- | --- | --- |
| `admin` | `atk2026` | 管理员 | 全部新人、打卡、闯关、阶段配置、账号权限 |
| `ken` | `atk2026` | 领导人 | 自己带的新人，可审核点评 |
| 新人手机号 | `123456` | 新人 | 只看到自己的进度，可提交打卡 |

> 上线后请第一时间修改默认密码（「我的 → 修改登录密码」）。

## 四阶段培养体系（可在「阶段配置」里改）

1. **阶段一 · 价值确认，定心定位（10 天）**：每天 1 个视频（8 个目录循环）+ 打雾 2 位 1 星以上嘉宾（阶段累计 30 人）+ 语音会后会反馈；Day1~Day10 主题已内置。
2. **阶段二 · 闯关阶段**：连续 15 天语音会后会 + 月度 Ken 哥课堂 / 全人类大会 + 大闯关四选一（产品示范 / 复数 / 游场讲 PPT / 三大员）+ 时间表 + 创业改变的 20 个理由。
3. **阶段三 · 开业阶段**：讲解开业七件事（重复 1-3 次）+ 语音反馈会后会内容。
4. **阶段四 · 市场前期**：回答市场三问（做什么 / 怎么做 / 做的怎么样）并完成闯关。

团队黑话（打雾、P 仔、复 A、复数、Tup 对上…）在手机端「我的 → 团队名词」里有解释。

## 功能

- **登录页**：账号 / 手机号登录，三种角色权限隔离
- **数据看板**：在培人数、今日打卡率、本周打卡、待点评、打雾累计、平均总进度、逾期预警、闯关通过数、近 14 天趋势、阶段分布、连续打卡榜
- **新人管理**：列表筛选排序、新增/编辑/删除、详情抽屉（进度环、阶段流水线、打卡/闯关/档案分栏）、补录打卡
- **打卡记录**：按新人/日期/状态筛选，提交打卡（视频、Day 主题、打雾嘉宾逐条登记、语音反馈）、领导人打分点评
- **闯关考核**：四类闯关登记与通过、大会/课堂参加记录
- **阶段配置**：阶段定义、每日动作标准、视频目录、Day 主题、开业七件事、三大员等全部可编辑
- **账号权限**：账号增删改、角色分配、重置密码
- **数据备份**：导出全量 JSON / 导入恢复 / 一键清空业务数据（在「阶段配置」页底部）

## 数据

- 存储：`data/db.json`（原子落盘，写操作防抖合并）
- 备份：管理员在「阶段配置 → 数据备份与恢复」导出 JSON；换环境或误删后导入即可
- 清空：同一处的「清空业务数据」会删除全部新人 / 打卡 / 闯关 / 大会记录与新人账号，保留管理员账号与配置

## 目录

```
server/   后端：HTTP 服务、鉴权、存储、进度计算、演示种子数据
shared/   领域模型（阶段/视频/主题/闯关的业务配置唯一真源）
public/
  shared/ 双端共用的 css 与 js（api 封装、UI 组件、表单、图表、格式化）
  web/    网页版（侧边栏 + 6 个页面）
  m/      手机端（底部 tab + 4 个页面）
data/     db.json
```

## 上线注意

- 服务监听 `$PORT` 并绑定 `0.0.0.0`，可直接部署
- 重新部署会用本地 `data/db.json` 覆盖线上数据：**更新前先在线上导出一份备份**，部署后再按需导入
- 无数据库依赖，但也不提供数据库：数据量很大时建议改为接入外部存储
